# 上线配置必备清单

生成日期：2026-06-17

本文档只保留正式上线必须确认或替换的配置。当前项目里的微信小程序 AppID 和 uniCloud 云空间都不是公司主体，不能直接用于正式上线。

## 一、当前结论

- 小程序正式上线必须换成公司主体的微信小程序账号。
- uniCloud 必须换成公司主体的正式云空间。
- AppSecret、支付密钥、证书私钥不能写进前端代码或仓库，只能配置在 uniCloud 环境变量或平台后台。
- PC 后台正式包必须显式配置正式云函数 URL，不能依赖当前测试云空间兜底地址。

## 二、必须拿到的信息

| 必备信息 | 用途 | 当前状态 |
| --- | --- | --- |
| 公司主体微信小程序 AppID | 小程序构建、登录、支付、订阅消息 | 现有 AppID 不是公司主体，必须更换 |
| 公司主体微信小程序 AppSecret | 云函数换 openid、access_token | 还未拿到，后续配到 uniCloud 环境变量 |
| 公司主体 uniCloud 正式云空间 | 部署云函数、数据库、云存储 | 现有云空间不是公司主体，必须更换 |
| 正式云函数 URL 化地址 | PC 后台访问管理接口、支付回调 | 需要在正式云空间开启 URL 化 |
| PC 后台正式域名 | 部署管理后台 | 还未拿到 |
| 微信支付商户资料 | 小程序在线支付 | 若正式上线保留微信支付，则必须提供 |
| 订阅消息模板 ID | 报修、报价、付款、发货、完成提醒 | 需要在正式小程序后台申请 |
| 微信后台合法域名 | 真机和线上请求、上传、下载 | 需要用正式域名重新配置 |
| 公司正式资料 | 客服电话、客服微信、二维码、寄修地址、公司介绍、Logo | 项目里已有内容需要公司确认后才能作为正式资料 |
| 正式后台管理员账号 | PC 后台登录和运维 | 不能使用本地 mock 的 `admin / admin123` |

## 三、必须改的位置和改法

### 1. 小程序 AppID

| 文件 | 改哪里 | 怎么改 |
| --- | --- | --- |
| `docte-master/manifest.json` | `mp-weixin.appid` | 改成公司正式小程序 AppID |
| `docte-master/project.config.json` | `appid` | 改成公司正式小程序 AppID |
| `docte-master/manifest.json` | 顶层 `appid` | 如果公司要用自己的 DCloud 应用，也改成公司正式 uni-app 应用 ID |

### 2. 小程序 AppSecret 和微信能力

这些不改前端文件，改正式 uniCloud 云函数环境变量：

```text
WX_APPID=公司正式小程序 AppID
WX_SECRET=公司正式小程序 AppSecret
```

涉及云函数：

- `docte-master/uniCloud-alipay/cloudfunctions/cicada-client-user`
- `docte-master/uniCloud-alipay/cloudfunctions/cicada-client-order`
- `docte-master/uniCloud-alipay/cloudfunctions/cicada-admin-order`

注意：`docte-master/config/wechat.js` 里的 `your-appid`、`your-appsecret` 不能填正式密钥；当前未发现它被正式业务引用。

### 3. 正式 uniCloud 云空间

正式云空间需要重新部署：

- 云函数：`cicada-client-user`
- 云函数：`cicada-client-order`
- 云函数：`cicada-client-public`
- 云函数：`cicada-admin-sys`
- 云函数：`cicada-admin-kb`
- 云函数：`cicada-admin-order`
- 数据库集合和索引：按 `docte-master/uniCloud-alipay/database/INDEXES.md` 创建

上线前不要把测试数据、测试账号、测试订单导入正式库。

### 4. 微信支付

如果正式上线保留微信支付，在 `cicada-client-order` 的正式云函数环境变量中配置：

```text
WX_PAY_APPID=公司正式小程序 AppID
WX_PAY_MCH_ID=微信支付商户号
WX_PAY_SERIAL_NO=商户 API 证书序列号
WX_PAY_NOTIFY_URL=正式支付回调 URL
WX_PAY_PRIVATE_KEY_BASE64=商户 API 私钥 base64 内容
WX_PAY_API_V3_KEY=微信支付 APIv3 密钥
```

支付回调 URL 必须指向正式云空间 URL 化后的 `cicada-client-order/wechatPayNotify`。

### 5. 订阅消息模板

在正式小程序后台申请模板后，把模板 ID 配到正式云函数环境变量：

```text
WX_SUBSCRIBE_TEMPLATE_REPAIR_SUBMITTED=报修提交提醒模板 ID
WX_SUBSCRIBE_TEMPLATE_ORDER_RECEIVED=设备签收提醒模板 ID
WX_SUBSCRIBE_TEMPLATE_QUOTE_ISSUED=维修报价提醒模板 ID
WX_SUBSCRIBE_TEMPLATE_PAYMENT_CONFIRMED=付款确认提醒模板 ID
WX_SUBSCRIBE_TEMPLATE_ORDER_SHIPPED=回寄发货提醒模板 ID
WX_SUBSCRIBE_TEMPLATE_ORDER_COMPLETED=工单完成提醒模板 ID
```

涉及云函数：

- `cicada-client-public`
- `cicada-client-order`
- `cicada-admin-order`

### 6. PC 后台正式地址

在 `pc-admin/.env.local` 或部署平台环境变量中配置：

```text
VITE_UNICLOUD_BASE_URL=正式云函数 URL 化基础地址
VITE_ADMIN_SYS_URL=正式 cicada-admin-sys URL
VITE_ADMIN_KB_URL=正式 cicada-admin-kb URL
VITE_ADMIN_ORDER_URL=正式 cicada-admin-order URL
VITE_CLIENT_PUBLIC_URL=正式 cicada-client-public URL
```

必须检查这些位置不能继续使用测试云空间兜底地址：

- `pc-admin/src/config/api.js`
- `pc-admin/scripts/check-admin-urls.mjs`
- `pc-admin/scripts/check-subscription-config.mjs`

PC 端切换正式地址后必须重新执行 `npm run build`。

### 7. 微信后台合法域名

在微信公众平台配置正式域名：

- `request合法域名`：正式云函数 URL 化域名、正式 HTTP API 域名
- `uploadFile合法域名`：正式上传域名，如果使用
- `downloadFile合法域名`：正式文件下载域名、云存储域名

本地开发里的 `urlCheck: false` 不能替代微信后台合法域名配置。

### 8. 公司展示和寄修资料

这些内容上线前必须由公司确认后再替换：

| 内容 | 主要位置 |
| --- | --- |
| 客服电话、客服微信、热线说明 | `docte-master/pages/index/index.vue` |
| 寄修收件公司、收件人、电话、地址 | `docte-master/pages/index/composables/moduleConfig.js` |
| 公司介绍、品牌文案、统计数字 | `docte-master/pages/index/index.vue`、`docte-master/pages/company/index.vue` |
| Logo、客服二维码、调研二维码、海报 | `docte-master/static/`、`docte-master/config/cicada-assets.js` |

## 四、上线前最低验收

- 用公司正式 AppID 构建并在真机打开。
- 手机号授权登录成功，云函数能换到 openid。
- 报修提交成功，正式库生成工单。
- PC 后台用正式域名登录成功，并能读取正式库工单。
- PC 后台更新工单状态后，小程序端能看到同步变化。
- 微信支付能拉起、回调能到账确认。
- 订阅消息能发送或失败可追踪，不阻塞主流程。
- 客服、二维码、寄修地址、公司介绍全部为公司确认版本。
- 正式包不再依赖 localhost、mock、测试云空间、测试账号。
